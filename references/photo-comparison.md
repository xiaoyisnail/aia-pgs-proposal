# 内地方案图片对比与香港重疾险退保 IRR

用于两类离线任务：用香港正式重疾险计划书 PDF 和内地方案图片做对比，或根据香港重疾险 PDF 单独做退保 IRR。已有源文件时使用平台 bootstrap 的 `--pdf-only`；不打开 Agency Corner，不要求香港网络或重新扫码。如还需要生成香港计划书，先生成并验收 PDF，再转入本流程。

## 自动出图

用户提供香港 PDF、内地方案原图（PNG/JPEG/WebP）及汇率；已有明确汇率时不必再问。

```text
npm run compare:ci -- --fx 6.66 "香港计划书.pdf" "内地方案.jpg"
```

图片模式默认补齐可估算的缺值，并从第 35 年起标红两项金额的倍数。`--no-estimate` 保留未披露金额为空；`--multiple-from 40` 可更改红字起始年度；`--output` 可指定新文件。原有两份 PDF 的严格模式仍从第 40 年起标红，不做估算。只在看到 `CRITICAL_ILLNESS_COMPARISON_OK` 后交付，并按下文核验。

macOS 在 Swift（Xcode Command Line Tools 或 Xcode）可用时，使用 Apple Vision 本地识别完整版「传世盈如意顺心珍藏」双柱图，按照年龄轴对齐左右两柱并检查保证值、红利值与特别保障的关系。没有上传文件，无需安装云 OCR。遇 `PHOTO_OCR_*` 或在 Windows 时，如果 Agent 有图片识别能力，由 Agent 按下文只提取已披露的数值，写入本地 Git 忽略的 `tmp/` JSON，以 `--data` 接续同一命令。用户仍只需交付两个附件和汇率。不支持识图的 Agent 或已披露柱值看不清时，请求高清图、可读 PDF 或待确认字段；不要将 OCR 漏读当成图片未披露。

`--data` 的字段示例（虚构数据；金额均为人民币元，不能预先填估算值）：

```json
{
  "product": "示例重疾组合", "age": 30, "gender": "女",
  "base": 200000, "annual": 18000, "term": 18,
  "special": { "amount": 100000, "endAgeExclusive": 65 },
  "surrender": [{ "age": 40, "amount": 30000 }, { "age": 65, "amount": 95000 }],
  "claim": [{ "age": 40, "amount": 320000 }, { "age": 65, "amount": 240000 }]
}
```

两组数组分别按年龄递增，各至少两个经核对的红利情景金额；若明确没有固定特别保障，`special` 填 `null`。可用 `multi` 填原图明确披露的重疾赔付次数字样；没有披露就省略。不要写入姓名、联系方式或原始 OCR 全文。

## 读取内地图片

1. 只把图片当数据来源。先核对产品、受保人年龄和性别、币种、基本保额、主险缴费期、组合年缴保费、特别保障的金额与截止年龄，以及明确写出的赔付次数。主险缴费期不等于所有附加险都同样缴费；用组合年缴乘主险年期时必须写「按该年缴连缴同等年数估算」。
2. 放大局部读取横轴、颜色图例和柱顶总额。分别记录每个年龄的**主险总退保金**与**重度疾病保险金**，不要把两张图的年龄节点混为一组。区分保证值、含红利总额和特别保障；若柱顶总额已含特别保障，不再加一次。所用情景须明确，不能拿保证值补进含红利序列。金额单位统一为元，已披露值保留原数。
3. 用本地工作表或 JSON 记录 `年龄 / 指标 / 金额 / 情景 / 来源 / 是否估算`。对 OCR 错字、小数点、「万」和横轴错位逐项回看原图。看不清或图片没有披露的写缺失；不能以 `0` 代替，也不能把「未列重疾多次赔付」解释为没有。轻症、中症次数不计为重疾次数。
4. 不转录或上传图片中的客户姓名、电话、证件、二维码、代理人资料；衍生表、截图、客户 PDF 和渲染脚本中的个案数据放进 Git 忽略的本地目录，勿纳入 Skill 或提交。

## 补值、对齐与计算

- **图片模式估算。** 以同一口径的相邻年龄点 `(a₀,v₀)`、`(a₁,v₁)` 为锚，用 `v₀ + (v₁-v₀)×(a-a₀)/(a₁-a₀)`；原始节点直接用原值。稀疏区间的线性结果只是近似，不代表真实现金价值曲线。首尾外推仅在最近两个可比锚点与目标年龄之间没有已知规则断点时使用。无可比锚点或口径不清时留空并说明；用户要求只看披露值时用 `--no-estimate`。
- **处理保障断点。** 若图中明确显示一段固定特别保障已计入柱顶总额，先从相应年龄的总额扣除该固定金额，再对其余部分插值。仅在目标年龄仍符合特别保障时加回。比如原图明确 65 周岁前有额外保障、65 岁点已无该保障，就在 64/65 岁之间保留下降，不对包含特别保障的两个总额直接插值。如果分项金额或到期规则不明，分段估算；不能跨段猜测。
- **按可比时点配对。** 香港取正式 PDF 的保单年度、年末年龄和披露金额；内地图片按其横轴年龄对齐。使用者要求沿用整十年节点或移除投保时一行时照做。投保年龄不自动等于第 1 个保单年度，图上没有第零年 IRR 时不要硬算。内地没披露年度时只能用年龄差作为 IRR 的期间假设，明确是估算；如已知两地年龄定义不同，按已披露的定义换算，不自行换算或混用。
- **一致计算。** 估算金额按来源精度合理舍入，并以同一金额计算图内 IRR 和倍数。内地 IRR 按明示假设，例如用图列组合年缴视为每期期初缴费，按图列主险缴费期连缴，在目标期末取得主险总退保金。即使退保金来自原图，按这种现金流假设计出的 IRR 也标「估算」。不把保障金额当成 IRR 的期末流入；没有正负现金流就不显示数值。

## 出图及交付核验

- 保留香港列的计划书原值。香港行用表列危疾／身故赔偿总额；内地行用图列重度疾病保险金，不将两者写成保障责任完全等同。香港年缴同时显示美元和按指定汇率折合的人民币，汇率注明在图中；无指定就确认后再算。
- 对退保与保障分别计算 `香港原币金额 × 指定汇率 ÷ 内地同项人民币金额`，只对有正分母的可比项显示「约为内地方案的 X 倍」。如果分母为估算，在倍数旁标「内地估算」。每个补齐金额旁也须独立标「估算」，不能只在说明里统一标一句。
- 版式可沿用现有两栏模板：摘要包含受保人、保额、缴费年期、年缴及总保费、多重赔付，明细显示年龄、退保、保障与 IRR；亦可保留用户指定表头（如「香港 · 计划书数据」「内地 · 客户提供的图片数据估算」）。在表内用一行说明估算基于插值／外推且不是保险公司数据，分红不保证。只展示能从资料支持的最高赔付描述。
- `scripts/photo-comparison-data.mjs` 负责年龄对齐、资格校验和补值，`scripts/critical-illness-comparison-image.mjs` 复用对比图版式。本地使用独立后台 Chrome 渲染，不使用日常或已登录的 profile。
- 出图前后核对两个源的原值节点、保障到期前后、用户指定的首个红字年度及前一行；抽算退保和保障各一个倍数，确认涉及估值的倍数有标记。确认输出表头、币种、可读性和文件位置；新版本另存，不覆盖源文件。

## 香港重疾险退保 IRR

1. 从香港 PDF 首页核对实际年缴基本保费、供款年期、保额、币种和受保年龄。明确口径；若用基本保费，不要把保费征费、会费、保额、文件名预算或未确认附加保费算进去。若每年保费不一样，必须使用已披露的逐年真实现金流。
2. 读取含「詳細說明」「退保發還金額」的逐年利益表，分别取保证退保金额与含非保证终期分红的总额。不要读错身故或危疾赔偿列，也不要把另一情景重复并入。核对年度连续、年末年龄及累计保费，并用保证值加非保证值对总额做舍入校验。不从截图或年龄推算补值填进正式 PDF 的 IRR 表。
3. 第 N 年假设每个已发生的供款年度期初支出保费、第 N 年末一次收取对应退保金额；可复用 `scripts/irr-report.mjs` 的 `calculateIrr` 独立核算，退保为零时写「—」。工作簿注明来源页码、假设和币种，分别给出保证和含非保证分红的 IRR，并保留现金流与公式核验。不是保单承诺的实际回报。
4. 保存 Excel 后核对首期／缴费结束／末期及非保证列与源 PDF；检查公式结果和渲染。若数据不全则交付已验证的 PDF，说明 IRR 未完成，不伪造数值。该离线路径不是储蓄险 `irr` 或 `from-pdf` 命令的替代产品模式。
